# Y-B-TOOL v2.8

Budget / technical offer generator for ICL compressors (Baker Hughes Thermodyn, DTI).

Run: `python y_b_tool.py`

Next to the script, keep:
- `Technical_Proposal.docx` (Word master)
- `DB-2026/` (document library, one folder per document)
- the contacts Excel file

Python packages: openpyxl, pillow, reportlab, pypdf (pywin32 optional on Windows).
